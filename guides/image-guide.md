# 블로그 이미지 제작 가이드

블로그 글에 들어갈 대표 이미지와 본문 삽입 이미지를 만들 때 따르는 가이드예요.

## ⚠️ 왜 이 가이드가 다양성을 강제하는가

네이버 알고리즘은 "동일 구조·동일 톤을 반복 발행하는 계정"을 자동 생성 콘텐츠로 의심해요. 이 블로그는 거의 매일 발행되는 구조라, **대표 이미지가 매번 똑같은 색상·레이아웃이면 그 자체로 "찍어낸 콘텐츠" 신호가 됩니다.** 아래 팔레트/레이아웃 로테이션은 장식이 아니라 노출 방어 장치예요 — 매번 같은 조합을 쓰지 말 것.

---

## 대표 이미지 규격

- **크기**: 가로 1080px, 세로 1080px (1:1 정사각형)
- **메인 텍스트**: 글 제목 (큰 글씨, 흰색 또는 배경과 대비되는 색)
- **보조 텍스트**: 카테고리나 부제 (작은 글씨, 연한 톤)
- **폰트**: Pretendard 또는 시스템 기본 한글 폰트

### 배경 팔레트 — 그날 시황/주제 분위기에 맞춰 아래 중 하나를 고른다 (매번 같은 걸 쓰지 말 것)

| 팔레트 | 색상 | 언제 쓰나 |
|---|---|---|
| 네이비-퍼플 | `#1a1a2e` → `#16213e` | 하락·약세 마감 |
| 딥그린-틸 | `#0f2027` → `#134e4a` | 상승·반등 마감 |
| 버건디-마룬 | `#2d0a0a` → `#4a1414` | 급락·쇼크성 뉴스 |
| 슬레이트-그레이 | `#232526` → `#3a3d40` | 보합·횡보, 방향성 불분명한 날 |
| 딥퍼플-와인 | `#1e0a3c` → `#3d1a5c` | 포트폴리오 점검·개인 소회 글처럼 시황과 무관한 주제 |

- 같은 팔레트를 3일 연속으로 쓰지 않는다. 직전 며칠 폴더(`output/`)의 `images/thumbnail.png`를 확인해서 최근에 안 쓴 팔레트를 우선 고른다.
- 팔레트뿐 아니라 **레이아웃도 최소 2~3가지를 번갈아 쓴다**: (a) 텍스트 중앙 정렬 + 하단 액센트 도형, (b) 텍스트 좌측 정렬 + 우측 큰 숫자/퍼센트 강조, (c) 상단 배지(카테고리 라벨) + 중앙 큰 타이틀. 액센트 위치(우하단/좌상단/없음)도 매번 고정하지 않는다.

## 본문 삽입 이미지 종류

글 내용에 맞게 아래 네 가지 중 선택해서 사용해요. **매 글 똑같은 순서/조합으로 쓰지 말고, 그날 데이터 성격에 맞는 걸 고른다** (예: 시계열 흐름이면 단계별 다이어그램, 종목 여러 개 비교면 표, 핵심 한두 개만 강조하고 싶으면 카드).

1. **비교 표** — 제품/방법을 나란히 비교할 때
2. **단계별 다이어그램** — 절차나 순서를 보여줄 때
3. **핵심 포인트 카드** — 3~5개 요점을 정리할 때
4. **인용/강조 박스** — 중요한 한 마디를 강조할 때

같은 글 안에서도 4가지 템플릿을 섞어 쓰는 게 좋다(전부 카드형이면 단조로워 보임). 단, **상승=빨강/하락=파랑(한국 증시 표기 관례)은 절대 바꾸지 않는다** — 여기서 말하는 "다양화"는 이 관례색이 아니라 배경·테두리·강조박스 등 장식용 포인트 컬러를 그날 배경 팔레트의 보조색에 맞춰 살짝 바꿔주라는 뜻이다.

## 이미지 출처에 대한 솔직한 원칙

- 이 파이프라인이 만드는 이미지는 실제 스크린샷이 아니라 **데이터를 시각화한 합성 그래픽**이다. `draft.md`에 "스크린샷"이라는 표현이 남아있어도 실제로는 이 합성 그래픽으로 대체하는 것이 맞다 — 없는 사진을 찍은 척 캡션을 달지 않는다.
- 사용자가 실제 사진(증권사 앱 캡처 등)을 `user-images/`에 넣어준 경우에만 그 파일을 그대로 쓴다. 이 경우가 원본성 신호로는 가장 강하니 있으면 최우선으로 활용한다.
- 매번 다른 팔레트·레이아웃·템플릿 조합을 쓰는 것 자체가 "이 계정은 매 글을 새로 디자인한다"는 신호를 만드는 목적임을 기억할 것 — 작업 속도를 위해 이전 글의 HTML/CSS를 그대로 복사해서 텍스트만 바꾸는 건 이 가이드의 취지에 반한다.

---

## 공통 규칙

- 모두 HTML + CSS로 만들고, Python으로 Playwright를 실행해서 PNG로 캡처한다.
- 배경 톤은 본문과 어울리게 깔끔하고 단순하게 유지한다.
- 텍스트는 최대한 짧게 — 이미지는 보조 수단이다.
- 코드 블록 스타일을 디자인 요소로 활용 가능 (모노스페이스 폰트, 어두운 배경).
